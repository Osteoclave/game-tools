# Wheel of Fortune Puzzle Injector
# Sample puzzle file
# Enemies and items from EarthBound (SNES, 1995)
#
# ------------------------------------------------------------------------
# Puzzle file format
# ------------------------------------------------------------------------
# - Comments are prefixed with "#"
# - Empty lines are silently ignored
# - Puzzle lines have the following format:
#    - category:answer/lines
#
# - Category
#    - Leading and trailing spaces will be trimmed
#    - The category must be 1-8 characters from the following set:
#       - space, dollar sign, apostrophe, dash, question mark,
#         numbers 0-9, letters A-Z, letters a-z
#    - Lowercase letters will be displayed as uppercase in-game
#
# - Answer lines
#    - One to four answer lines, separated by slashes
#    - Leading and trailing spaces will be trimmed from each answer line
#    - Answer lines can only contain characters from the following set:
#       - space, apostrophe, dash, letters A-Z, letters a-z
#    - Lowercase letters will be displayed as uppercase in-game
#    - The complete answer must contain at least one consonant
#       - "Y" is always treated as a consonant in Wheel of Fortune
#    - Answer lines cannot exceed the available space on the game board
#       - 1 answer line  =      13           character limit
#       - 2 answer lines =      13 / 13      character limit
#       - 3 answer lines = 11 / 13 / 13      character limit
#       - 4 answer lines = 11 / 13 / 13 / 11 character limit
#
# - Advanced formatting for answer lines
#    - Normally, answer lines are centered on the game board, using an
#      extra square on the left if equal centering isn't possible
#    - You could adjust the alignment with leading or trailing spaces,
#      except that those get trimmed from each answer line
#    - To preserve leading and trailing spaces, you can either:
#       - Replace the spaces with underscores
#       - Double-quote the answer line in question
#
# - Puzzle lines that don't meet the constraints above will be skipped
#   over, and their line numbers reported on the Lua output console
# - A properly-formatted puzzle file will report: "0 puzzles skipped"
# ------------------------------------------------------------------------
